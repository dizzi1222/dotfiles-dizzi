Use OpenCode's built-in `todowrite` tool (not a Markdown file) to create or update the checklist for this session.

Goal or context: $ARGUMENTS

- If a checklist already exists, update it instead of replacing it; preserve completed items.
- Break the goal into short, concrete, verifiable tasks.
- Mark the current task `in_progress`, future tasks `pending`, and mark tasks `completed` only after doing and verifying them.
- Keep the checklist concise and report the resulting items.
- If no arguments were supplied, infer the active goal from this conversation.
